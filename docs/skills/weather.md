# weather

Get current weather conditions and forecasts for any city worldwide.
Uses the wttr.in service — no API key required.

## Usage

Provide a city name to get current conditions plus a 3-day forecast.
Supports location formats: city name, airport code, IP address, domain name.

## Examples

- "Weather in Paris" → current conditions + forecast
- "Weather in LAX" → weather at Los Angeles airport
- "Weather in 10001" → weather for NYC zip code

## Output

Returns temperature (°C/°F), humidity, wind speed, precipitation, and UV index.
